# 0001 Static site instead of WordPress

Context: WordPress + Newspaper theme left ~80% demo content, exposed usernames, and noindex on every page.
Decision: Plain static site in GitHub, deployed to Pages.
Alternatives: Astro (good if the site grows past ~6 pages); keep WordPress with a new theme (keeps upkeep and attack surface).
Consequences: No logins, no plugin updates, free hosting. Content edits happen through GitHub (or a simple CMS later).

# 0002 Colourful dark theme, content from 2025 profile

Context: Asked for a colourful version; the 2025 profile uses black with orange, pink, teal and yellow confetti.
Decision: Dark stage base; each music form on the dial has its own colour and repaints the page when tuned.
Consequences: All copy now comes from the 2025 profile only; School of Music, phone, email and address removed until confirmed.

# 0003 Maroon theme, YouTube up top, Bhajana Bharata page

Context: Dark theme did not match the vibe; YouTube titles needed a prominent place; Bhajana Bharata is the flagship concert.
Decision: Maroon/gold palette; YouTube block right after the hero; dial stations link a matching channel video; separate bhajana-bharata.html with flipping KN/EN logo and a pinned sideways-scroll procession (native horizontal scroll on phones).
