# harshadhwani.in

Concept rebuild of the HarshaDhwani site ("Tune the dial" theme).

## Edit
- Text and facts: `content/site.json`, then the matching text in `index.html`.
- Photos: add WebP files to `img/` (max 1400px) and reference them with alt text.

## Deploy (GitHub Pages)
1. Push to `main`.
2. Settings → Pages → Deploy from branch → `main` / root.
3. DNS: CNAME `www` → `<user>.github.io`; redirect the bare domain to www.
